# Django Book Library Application

This is a simple Django application for managing a book library. Users can add, edit, and delete books, as well as view a list of all available books.

## Features

- Add new books to the library
- Edit existing book details
- Delete books from the library
- View a list of all books with details
- will be added soon user login auethencation 

## Requirements

- Python 3.x
- Django 3.x or or more than 3
- SQLite (default database) or any other database supported by Django
